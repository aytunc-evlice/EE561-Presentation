## Workflow

```bash
git pull            # before you start working
git add -A
git commit -m "..."
git push            # when you're done
```

Slides (`.pptx`) and Simulink models (`.slx`) are binary and can't be merged —
tell each other before editing the same file, or work on separate copies.
