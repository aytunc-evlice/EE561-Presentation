Question 2 · Designing a neutral-point balancing loopbalancing and control25 pts

A 3-level NPC with carrier PWM has a split DC link of 2 × 3.3 mF; an ideal source holds vC1 + vC2 constant, so C dΔV/dt = iO with ΔV = vC1 − vC2 and iO drawn from the midpoint. The phase currents are balanced with Î = 40 A, and m = 0.9. A common offset r0 is added to all references.

  1. Starting from ⟨iO⟩ = Σx(1 − |rx + r0|) ix, derive ∂⟨iO⟩/∂r0 and its average over a fundamental period for rx = m cos θx, ix = Î cos(θx − φ). [6]
  2. With r0 = K · sign(P) · ΔV, derive the closed-loop time constant and choose K for τ = 20 ms at cos φ = 0.8. [6]
  3. With the same K, what is τ at cos φ = 0.2? What happens in rectifier mode if sign(P) is omitted? [5]
  4. At unity power factor the midpoint current contains a third harmonic of amplitude 8mÎ/(5π). Estimate the peak-to-peak ripple of ΔV. Can — and should — the balancing loop remove this ripple? [8]

Solutions and marking guide

Solution 1 · Three-level space-vector modulation25 pts

(a) v* = 0.85∠15° = (0.821, 0.220). Nearest vectors: small ONN/POO (0.667, 0); large PNN (1.333, 0); medium PON (1.000, 0.577). [4]

(b) β: 0.577 dPON = 0.220 → dPON = 0.381;   dS + dL = 0.619. α: 0.667 dS + 1.333 dL + 0.381 = 0.821 → dL = 0.041, dS = 0.578. [8]

(c) ONN (0.145) → PNN (0.020) → PON (0.190) → POO (0.289) → PON (0.190) → PNN (0.020) → ONN (0.145). Transitions: phase a O→P, phase b N→O, phase c N→O, then back in reverse; each phase switches once up and once down per period. [6]

(d) iO: ONN = +ia; PNN = 0; PON = +ib; POO = ib + ic = −ia. To reduce ΔV we need ⟨iO⟩ < 0: lengthen POO and shorten ONN, keeping their sum at 0.578. Both states produce the same space vector, so the output (line-to-line) voltage does not change — only the midpoint charge does. [7]

Solution 2 · Neutral-point balancing loop25 pts

(a) For an offset small enough not to change the sign of any rx: ∂⟨iO⟩/∂r0 = −Σx sign(rx) ix. Since ⟨sign(cos θ) cos(θ − φ)⟩ = (2/π) cos φ for each phase, the period average is −(6/π) Î cos φ. [6]

(b) C dΔV/dt = −(6/π)Î cos φ · K sign(P) ΔV = −(6/π)Î|cos φ| K ΔV → τ = πC/(6ÎK|cos φ|). For τ = 20 ms: K = π · 3.3×10−3/(6 · 40 · 0.8 · 0.02) = 2.7 × 10−3 V−1 (an offset of 0.027 per 10 V of imbalance). [6]

(c) τ ∝ 1/|cos φ|: τ = 20 ms × 0.8/0.2 = 80 ms. Without sign(P), cos φ < 0 in rectifier mode makes the loop gain positive: ΔV grows exponentially until saturation and an overvoltage trip. [5]

(d) ÎO3 = 8 · 0.9 · 40/(5π) = 18.3 A at 150 Hz. Integrating, ΔVpp ≈ 2ÎO3/(3ωC) = 2 · 18.3/(3 · 314 · 3.3×10−3) ≈ 11.8 V (a numerical integration gives 11.9 V). The loop bandwidth is about 1/(2πτ) ≈ 8 Hz, far below 150 Hz, so it cannot remove the ripple — and it should not try: the ripple is inherent to carrier PWM with zero average, and chasing it would only inject large offsets. It is handled by sizing C (or by modified modulation). [8]
